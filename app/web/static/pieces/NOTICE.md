# Chess piece artwork

The twelve SVGs in this directory are the **Cburnett** set: the default pieces on
Lichess and the ones Wikipedia's chess diagrams are drawn with.

- Author: Colin M.L. Burnett (<https://en.wikipedia.org/wiki/User:Cburnett>)
- Source: <https://commons.wikimedia.org/wiki/Category:SVG_chess_pieces>, via
  <https://github.com/lichess-org/lila/tree/master/public/piece/cburnett>
- Vendored unchanged, for the same reason htmx and Chart.js are: the brief asks
  for one deployable, and a CDN would make the page depend on a host we do not
  run.

of:

**We take the BSD option**, reproduced below. It asks for the copyright notice
and disclaimer to be kept and nothing else: no share-alike, no copyleft, and no
question about what the licence of the surrounding page might be. Lichess lists
this same set as GPLv2+ in their `COPYING.md` because that is the option *they*

Do not edit these files without re-reading the above. Editing is still allowed
under BSD, but the notice then has to travel with the edited version too.

A CC0 set (`rhosgfx`, from the same Lichess directory) was tried here and
reverted: it is coloured and illustrated where these are line drawings, and the
board is built around a set that is drawn rather than tinted. Keeping the
notice below is the cheaper price.
